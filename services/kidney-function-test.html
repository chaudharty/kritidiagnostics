GENERAL INFORMATION

About kidney function testing

Tests associated with kidney function can include measurements from blood and, in some cases, urine. The exact tests depend on the question being assessed. A single result should not be used to self-diagnose; interpretation belongs with a qualified healthcare professional.

When might tests be requested?

A clinician may request testing for an evaluation, monitoring or follow-up when appropriate. The purpose and frequency should be discussed with the clinician who knows your health history.
